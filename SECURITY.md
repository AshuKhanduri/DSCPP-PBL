# Security Policy

## Supported Versions

Security updates and patches are applied to the active versions of **QuestForge**:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of QuestForge and its underlying native communication systems seriously. If you discover a potential vulnerability, please report it privately:

1. **Email the Project Maintainers**:
   - **Anushka Diwaker**: `anushkadiwaker9d@gmail.com`
   - **Ashu Khanduri**: `ashukhanduri07@gmail.com`
   - **Shobhit Rawat**: `shobhitrawat2150@gmail.com`

2. **Include Details**:
   - A description of the issue (e.g. buffer overflow in C engine, line-injection in IPC protocol, or unauthorized endpoint access).
   - Steps to reproduce or a minimal proof-of-concept.
   - The impact of the vulnerability.

3. **Response Timeline**:
   - You will receive an acknowledgment within 48 hours.
   - We will work to investigate, reproduce, and provide a patch within 7 business days.
   - Please refrain from disclosing the issue publicly until a fix has been released.
