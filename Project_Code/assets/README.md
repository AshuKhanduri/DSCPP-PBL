# Assets

Everything here is served from the site root by Vite (`publicDir: 'assets'`).
All art is cut from `reference/questforge_reference.webp` by
`scripts/extract_assets.py`; maps are generated by `scripts/build-maps.mjs`.

| Folder | Contents |
|---|---|
| `reference/` | The original reference sheet + `extracted_contact_sheet.png` (every extracted image) |
| `tilesets/terrain/` | 16x16 terrain tileset (`terrain.png`, `terrain.tsx` for Tiled) |
| `tilesets/{nature,town,castle,interiors,maze}/` | Props placed on maps (trees, houses, castle, shelves, hedges...) |
| `sprites/player/` | `player_male.png`, `player_female.png`: 4 rows (down, left, right, up) x 4 frames of 16x24 |
| `sprites/npcs/` | One sheet per NPC (3 frames: down, side, up) + `villagers.png`, `kids.png` |
| `sprites/objects/` | Interaction / world objects (doors, chests, anvil, forge, throne...) |
| `items/` | Item icons (inventory, notifications) |
| `ui/` | Dialogue frame, arrow, notification icons |
| `maps/` | Tiled JSON maps |
| `audio/` | Empty: no sounds exist yet |
